# 快捷键发现

## 本地配置与基线

`mac-hotkeys` 枚举 `/Applications`、`~/Applications` 及其子目录中的应用，并补充运行会话可见的应用。读取器识别系统偏好、KeyboardShortcuts 偏好、受支持应用的配置文件，以及 Keyboard Maestro、Alfred 和 Karabiner 的规则。应用未启动时，仍可列出保存的配置。双击、长按、同时键和重映射根据可识别的规则展示，设备、应用或变量条件标在来源中。

导出成功后的基线在 `~/Library/Application Support/mac-hotkeys/discoveries.json`。下次根据组合、软件和动作比较配置。首次运行时可用 `--baseline` 指定这个工具曾导出的 Markdown 报告，或 `mac-hotkeys list --json` 的输出。主动观察另行保存，并保留当时的 PID 和依据。可用 `--state-dir 目录` 建立独立的比较记录。

## 自动扫描

先在「系统设置 → 隐私与安全性」为运行命令的终端允许辅助功能和所需的输入监控权限，必要时重新打开终端。用 `mac-hotkeys scan --dry-run` 查看下一批候选，用 `--self-test` 单独检查权限和拦截。普通导出无需这些事件权限。

扫描独立组合字母、数字、部分标点、空格及 F13–F20 与多枚修饰键。它排除已有绑定、服务菜单快捷键、已知重映射的源键，以及退出、关闭、删除、剪贴板、常见终端控制和系统截图等高风险组合。默认每批最多 32 个，后续优先选尚未完整测量的组合。独占注册状态不参与筛选。用户自定义宏可能绑定在任何组合上，首次可用较小的 `--limit` 测试。

自检使用带标记的 F20 松开事件，验证起点、末端拦截器和独立后验拦截器。候选按下和释放成对投递。末端拦截旨在阻止原事件进入前台应用，位于拦截点之前的全局动作仍可能执行。检测到其他键盘输入、权限缺失或拦截异常时，扫描中止。主动模式只扫描单次组合，单独修饰键、真实硬件输入、双击和长按的覆盖依赖配置读取。

## 如何读主动观察

| 报告结果 | 依据 |
| --- | --- |
| 相关系统事件目标 | 观察到 `systemDefined/subtype 6` 特殊事件，目标 PID 为正数，且标记或按下时间戳唯一匹配。可解析时补上进程名称。事件本身不提供动作名或应用执行回执。 |
| 疑似占用，归属未知 | 观察到本次合成按下进入事件流，随后在末端前消失或被改写，对照仍然通过。本工具自身在末端正常拦截的按键不计入这一类。 |
| 时序或传递线索 | 同窗内出现系统事件，但证据不足以将该组合归给某一进程。 |
| 没有观察结果 | 本轮没有获得可报告的证据，监听器仍可能在后台处理按键。 |

macOS 的公开接口不保证每个全局快捷键都会产生上述特殊事件。仅凭普通按键的前台目标、Carbon 注册冲突或按键消失，无法确定快捷键的软件归属。[Apple 事件目标 PID](https://developer.apple.com/documentation/coregraphics/cgeventfield/eventtargetunixprocessid)

在 macOS 27.2.1 的受控测试中，独立进程拦截 F19 后，扫描器正确记录了“疑似占用，归属未知”。另一个测试进程成功注册了 F19；合成按键抵达测试窗口，但没有触发其 Carbon 热键回调，也没有出现可归属的 subtype 6 事件。因此合成扫描在此环境会漏掉真实注册项。
